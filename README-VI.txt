Bản này là website tĩnh, không cần Node.js và không cần server.

CÁCH ĐĂNG MIỄN PHÍ:
1. Tạo tài khoản GitHub.
2. Tạo repository Public.
3. Upload toàn bộ file trong thư mục này vào repository.
4. Vào Settings > Pages.
5. Source: Deploy from a branch.
6. Branch: main, Folder: /(root), rồi Save.
7. Chờ vài phút và mở đường dẫn do GitHub Pages cung cấp.

QUAN TRỌNG:
- Phải giữ tên file index.html.
- Không upload cả thư mục lồng bên ngoài; index.html phải nằm ngay trang đầu repository.
- GitHub Pages không chạy server.js, vì vậy bản này đã bỏ backend Node.js.
